## 1. 完了した機能 (Done)

- [x] **標準ライブラリ（`std`）のみによる初期実装** (依存ゼロ軽量構成)
- [x] **主要CLIオプションの実装**:
  - `-h`, `--help`: ヘルプメニュー出力 (カテゴリ別グループ化 & デフォルト値表記)
  - `-v`, `--version`: バージョン情報表示
  - `--help-icons`: アイコン絵文字の対応一覧表を表示
  - `-i`, `--icons`: ディレクトリ/ファイル別絵文字アイコン表示
  - `-I`, `--no-icons`: アイコン非表示
  - `-s`, `--sizes`: ファイルサイズフォーマット表示 (`B`, `KB`, `MB`)
  - `-S`, `--no-sizes`: ファイルサイズ非表示
  - `-D`, `--dir-sizes`, `--du`: フォルダ配下の総ファイル数および総容量を集計表示
  - `-a`, `--all`: ドット (`.`) 隠しファイル表示
  - `-d`, `--depth`: ツリー探索の階層制限
  - `-e`, `--exclude`: 除外ディレクトリ名 / ワイルドカードパターンの指定
- [x] **ワイルドカード / Glob パターン除外機能 (`match_wildcard`)**:
  - 外部ライブラリなしで `*.tmp`, `*.log`, `build*`, `test?.rs` 等のパターン除外に対応
- [x] **ユニットテストの全領域への拡充**:
  - 引数解析 (`parse_arguments`) の正常系・異常系（未知オプション、値欠落、型エラー）テスト
  - サイズフォーマット (`format_byte_size`) の境界値テスト (0B, 1023B, 1024B, 1MB 等)
  - アイコン判定 (`get_icon_emoji`) の大文字小文字・新拡張子判定テスト
  - ワイルドカードマッチ (`match_wildcard`) の正常系・非マッチ系テスト
  - フォルダ集計 (`calculate_dir_summary`) の計算テスト
- [x] **アイコン判定モジュール (`src/icon.rs`) への分離・リファクタリング**
- [x] **Windows 10/11 ANSIカラー出力を自動有効化** (`kernel32.dll` ダイレクト FFI)
- [x] **ディレクトリ優先ソート機能** (視認性の向上)
- [x] **完全ドキュメンテーション体系の構築**:
  - `README.md` / `README_JA.md`
  - `SPEC.md`, `ARCHITECTURE.md`, `DIAGRAM.md`, `FOOTPRINTS.md`, `TODO.md`, `INSTRUCTIONS.md`, `CHANGELOG.md`
