# Rust製 Tree CLI ユーティリティ (Windows 導入手順)

このプロジェクトは、WindowsのコマンドプロンプトやPowerShellでディレクトリ構造を美しいツリー形式で出力するためのCLIツールです。標準ライブラリ（`std`）のみで構成されており、高速にコンパイルおよび実行が可能です。

---

## 🚀 導入手順

### ステップ 1: Rust のインストール
PCにRustのビルド環境がない場合は、まずRustをインストールします。

1. [Rust公式サイト (https://rustup.rs/)](https://rustup.rs/) にアクセスします。
2. `rustup-init.exe` をダウンロードして実行します。
3. 画面の指示に従い（デフォルトの `1` を入力）、インストールを完了させます。
4. インストール完了後、コマンドプロンプトまたはPowerShellを**新しく開き**、以下が成功することを確認します：
   ```bash
   cargo --version
   ```

### ステップ 2: プロジェクトの初期化
コマンドプロンプトやPowerShellで、本ツールをビルドするためのプロジェクトフォルダを新規作成します。

```bash
# 任意の作業用ディレクトリに移動
cd %USERPROFILE%

# 新しいバイナリプロジェクトを作成
cargo new tree-rs --bin
cd tree-rs
```

### ステップ 3: コードの書き換え
1. `Cargo.toml` の中身を、本ツールで生成した **Cargo.toml** の内容に書き換えます。
2. `src/main.rs` の中身を、本ツールで生成した **main.rs** の内容に全て上書きします。

### ステップ 4: リリースビルド
プロジェクトディレクトリで以下を実行し、最適化された実行ファイルをコンパイルします。

```bash
cargo build --release
```

ビルドが完了すると、次のパスに実行ファイル (`tree-rs.exe`) が生成されます：
```bash
.\target\release\tree-rs.exe
```

---

## 🛠️ Windows 環境でのグローバル登録 (PATHの追加)
コマンドラインで、いつでもどこからでも `tree-rs` コマンドを呼び出せるように環境変数を登録します。

### 手動での追加手順:
1. Windowsキーを押し、「**環境変数**」と入力して「**システム環境変数の編集**」を開きます。
2. 「**環境変数...**」ボタンをクリックします。
3. 「**ユーザー環境変数**」の中の `Path` を選択し、「**編集...**」をクリックします。
4. 「**新規**」をクリックし、先ほどビルドした `tree-rs.exe` が配置されているフォルダのフルパス（例：`C:\Users\YOUR_NAME\tree-rs\target\release`）を入力します。
   * もしくは、`tree-rs.exe` をすでにパスが通っているフォルダ（例: `C:\Windows` や独自の `C:\bin` など）に直接コピーしても構いません。
5. 全てのウィンドウの「OK」を押して閉じます。
6. コマンドプロンプトやPowerShellを**再起動**します。

## 💻 使い方・実行例

任意のフォルダに移動して実行します：

```bash
# カレントディレクトリのツリー表示
tree-rs

# 最大階層(深度)を2に制限して表示
tree-rs -d 2

# ファイルサイズとアイコンをつけて表示
tree-rs -s -i

# 特定のフォルダ (node_modules や target など) を除外して表示
tree-rs -e "target,node_modules"

# ドットから始まる隠しファイルも含めて表示
tree-rs -a

# 特定のディレクトリを指定してツリー表示
tree-rs C:\Users\Public
```
